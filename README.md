# Петровские паруса — интернет-магазин

Next.js + Supabase. Включены каталог, поиск и фильтр категорий, корзина, оформление заказа с самовывозом, выбор способа оплаты, базовая админ-панель.

## Важно перед запуском
- Каталог содержит демонстрационные позиции. Замените их через админ-панель.
- Заказы сохраняются в Supabase, если база подключена.
- Оплата «онлайн» пока является заготовкой выбора метода: реальное списание средств НЕ выполняется. Для запуска нужно подключить эквайринг (например, ЮKassa/Т-Банк) и реализовать создание платежа + webhook подтверждения.
- Телефон пока заглушка, добавьте рабочий номер.
- Изображения демо-товаров загружаются с Unsplash; для продакшена лучше загрузить собственные фото в Supabase Storage.

## 1. Создать Supabase
1. Создайте проект на https://supabase.com.
2. Откройте SQL Editor и выполните `supabase/schema.sql`.
3. В Authentication → Users создайте пользователя администратора.
4. Для пользователя назначьте `app_metadata.role = admin` через Supabase Dashboard / Admin API. Не используйте user_metadata для роли администратора.
5. В Project Settings → API скопируйте Project URL, anon key и service_role key.

## 2. Локальный запуск
Требуется Node.js 20+.
```bash
npm install
cp .env.example .env.local
```
Заполните `.env.local`:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY` — только сервер, никогда не публиковать и не добавлять в Git.

Затем:
```bash
npm run dev
```
Откройте http://localhost:3000. Админка: http://localhost:3000/admin.

## 3. Публикация
1. Создайте пустой репозиторий на https://github.com.
2. Загрузите файлы проекта или выполните:
```bash
git init
git add .
git commit -m "Initial store"
git branch -M main
git remote add origin https://github.com/ВАШ-АККАУНТ/ВАШ-РЕПОЗИТОРИЙ.git
git push -u origin main
```
3. На https://vercel.com импортируйте репозиторий.
4. В Vercel → Settings → Environment Variables добавьте три переменные из `.env.local`. `SUPABASE_SERVICE_ROLE_KEY` задайте только как серверную переменную без префикса NEXT_PUBLIC.
5. Deploy.

## 4. Как добавить администратора
В Supabase Dashboard откройте Authentication → Users, создайте пользователя. Затем через Admin API задайте ему app_metadata:
```json
{"role":"admin"}
```
После этого выйдите и войдите в `/admin` заново, чтобы обновился JWT.

## 5. Что потребуется перед коммерческим запуском
- Подключить и протестировать платёжный шлюз (успешная/неуспешная оплата, возвраты, webhook).
- Добавить редактирование существующих товаров и загрузку изображений в Storage (в текущей первой версии есть добавление и удаление; редактирование можно расширить следующим этапом).
- Добавить просмотр/изменение статусов заказов в админке.
- Указать телефон, часы работы, правила обработки персональных данных и публичную оферту.
- Проверить требования к онлайн-кассе/чекам и персональным данным для вашей юрисдикции.
